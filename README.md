# RankR — Legal

Öffentlich gehostete Rechtstexte (Impressum, Datenschutzerklärung, Nutzungsbedingungen, Löschung von Daten, Support, Quellen & Lizenzen) für die RankR App, veröffentlicht via GitHub Pages.

Live: https://benedikt-schreiner.github.io/rankr-legal/

Struktur wie `travel-delta-legal`: je Dokument ein Ordner mit `de.md` und `en.md`.

**Wichtig:** Die In-App-Texte (Impressum, Datenschutz) liegen zusätzlich als Dart-Konstanten in
`rankr/app/lib/features/profile/domain/legal_texts.dart`. Bei Änderungen beide Stellen pflegen
und „Stand“ aktualisieren.
